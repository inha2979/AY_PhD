# 🎓 Ayoub's Road to the PhD

A small browser exploration RPG about finishing a master's thesis on the way to a PhD.
Read papers, TA/RA, burn out a little, bake cookies, pet a white cat, get cheered on by In Ha, meet your professor, present at conferences.

## Play
Open the GitHub Pages link, or run a local server (opening index.html directly may block images):

    python3 -m http.server 8000
    # then visit http://localhost:8000

Controls: arrow keys / WASD to move, Space or Enter to interact and continue dialogue.

## Files
- index.html : page layout
- style.css : styles
- game.js : all game logic, text, balance numbers, and chiptune music (WebAudio)
- assets/ : sprites, backgrounds, portraits (PNG/JPG). Replace a file with the same name to swap art.

## Publish with GitHub Pages
Repo Settings > Pages > Deploy from a branch > main / (root).
